Sohbetler

Birine tıkla: kırılımlar yalnız o sohbeti gösterir.

Tutarlar nasıl okunur?

Dönemli tutarlar ve tokenlar orkestra token defterindendir; üstteki «Bugün» tutarıyla aynı kaynak. Token = giriş + çıkış + önbellek okuma + önbellek yazma. Dönemler: Gün bugün (saat saat), Hafta son 7 gün, Ay bu ay, Tümü ilk kayıttan bugüne. Orkestrasız çalışma alanlarında defter yoktur: sohbetin kayıtlı toplamı gösterilir (tahmini: açık sohbet, kaba: transkript tahmini). Hepsi API liste fiyatıyladır.
