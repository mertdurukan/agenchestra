# Symptom → Competing Causes → Discriminating Evidence

This is a **hypothesis catalogue, not a diagnosis**. A symptom may have several causes simultaneously. Rank hypotheses from local evidence and expected discriminatory value, not arbitrary confidence percentages. Do not bulk-apply every probe. Start at the first confirmed failing boundary.

For each candidate write: `Hypothesis / Why possible / If true we expect / Contrary observation / Safest decisive probe / Result / Scope / Evidence reference`.

## Candidate selection discipline

1. **Constrain the scope:** service, tenant, environment, version, time, user intent and expected invariant; note clocks and data freshness.
2. **Localize the first trustworthy divergence:** trace request or artifact across boundaries. If there is no trace, use boundary assertions and controlled comparisons.
3. **Keep competing hypotheses:** usually 2–3 top candidates, broaden only when tests eliminate them or a missing layer is uncovered.
4. **Choose a falsifying probe:** prefer tests with different predicted outcomes under candidates. Rank by potential information gain, operational risk, time/cost and availability.
5. **Interpret carefully:** evidence may support, weaken or fail to distinguish hypotheses. Explicitly mark confounders and negative findings.
6. **Select the correct layer:** routing policy for route errors, typed tool contract for argument errors, domain service for business-logic errors, retrieval stage for source drop, generation when good evidence reaches model but answer fails.
7. **Stop or escalate:** stop when the next choice is safe and further investigation will not change it; otherwise seek more evidence, contain, or report blocked. Never fake proof.

## Prevention + incident learning

A confirmed trigger is not the whole postmortem. Examine triggering event, preconditions, mechanism, impact amplification, detection gap and recovery difficulty. Record distinct mitigations, permanent corrective changes, preventive invariants/tests, detection, containment and recovery. Favor measurable owners and target checks; no single-point blame.
